## Recommended Teaching Workflow

```
📖 Reading → 🎤 Lecture → 💻 Notebook Demo → 🧪 Experiment → 📝 Exercise → 🎯 Assessment → 🚀 Project
```

| Step | Activity | Time | Location |

## Course Information

- **Course:** Tools and Techniques in Data Science
- **Module:** LangChain for Data Science
- **Level:** BS Data Science (3rd/4th year)
- **Prerequisites:** Python, Pandas, NumPy, basic ML concepts
- **Duration:** 8-12 weeks (adjustable)

## Teaching Philosophy

> Teach concepts first, APIs second. Students should understand WHY before HOW.

Every concept follows:
1. **Problem** — Why do we need this?
2. **Intuition** — What does it do in simple terms?
3. **Architecture** — How does it fit in the bigger picture?
4. **Code** — How do we implement it?
5. **Experiment** — What happens when we change parameters?
6. **Application** — Where is this used in Data Science?
