# Grading Rubrics

## Performance Levels

| Level | Description |
|-------|-------------|
| **Excellent** | Exceeds expectations, thorough, insightful |
| **Good** | Meets expectations, solid work |
| **Satisfactory** | Partially meets expectations, basic understanding |
| **Needs Improvement** | Does not meet expectations, significant gaps |

---

## Rubric 1: Notebook Exercises

| Criterion | Excellent (5) | Good (4) | Satisfactory (3) | Needs Improvement (<3) |
|-----------|---------------|----------|-------------------|----------------------|
| **Correctness** | All exercises correct | Most correct | Some correct | Few correct |
| **Understanding** | Shows deep understanding | Shows good understanding | Shows basic understanding | Shows minimal understanding |
| **Experimentation** | Thorough experimentation | Good experimentation | Basic experimentation | No experimentation |

---

## Rubric 2: RAG Assignment

| Criterion | Excellent (7) | Good (5-6) | Satisfactory (3-4) | Needs Improvement (<3) |
|-----------|---------------|------------|---------------------|----------------------|
| **Knowledge base** | 15+ docs, well-structured | 10+ docs | 5+ docs | <5 docs |
| **Retrieval** | High quality, metadata filtering | Good quality | Basic retrieval | Poor retrieval |
| **Generation** | Grounded, accurate, cited | Mostly accurate | Sometimes accurate | Often inaccurate |
| **Evaluation** | Comprehensive testing | Good testing | Basic testing | No testing |

---

## Rubric 3: Agent Assignment

| Criterion | Excellent (7) | Good (5-6) | Satisfactory (3-4) | Needs Improvement (<3) |
|-----------|---------------|------------|---------------------|----------------------|
| **Tool design** | 5+ well-designed tools | 3-4 tools | 2 tools | 1 or no tools |
| **Agent routing** | Smart, accurate routing | Good routing | Basic routing | No routing |
| **Error handling** | Comprehensive | Good | Basic | None |
| **Safety** | Input validation, logging | Some validation | Minimal | None |

## Rubric 5: Security Assignment

| Criterion | Excellent (7) | Good (5-6) | Satisfactory (3-4) | Needs Improvement (<3) |
|-----------|---------------|------------|---------------------|----------------------|
| **Input validation** | Comprehensive | Good | Basic | None |
| **Output validation** | Data leakage prevention | Some checks | Minimal | None |
| **Secrets management** | Proper handling | Environment variables | .env file | Hardcoded |
