# 📂 Data Directory

This directory holds sample datasets used in the notebook exercises and examples.

## What to Put Here

- **CSV files** — tabular data for analysis and Q&A experiments
- **PDF documents** — for RAG (Retrieval-Augmented Generation) exercises
- **Text files** — plain-text corpora for embedding and similarity search
- **JSON files** — structured data for agent and tool exercises

## Datasets Will Be Added

The notebooks will include cells that download or generate sample data automatically. You do not need to populate this directory manually before starting the tutorials.

## ⚠️ Important

- Do **not** commit large files (> 10 MB) to this repository
- Do **not** place any personal or sensitive data here
- Use Git LFS if you need to track large datasets
