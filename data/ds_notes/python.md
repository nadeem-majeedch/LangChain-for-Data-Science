# Python for Data Science

## Overview
Python is the most popular programming language for data science due to its simplicity, readability, and extensive ecosystem of libraries.

## Key Libraries
- **NumPy**: Numerical computing with arrays and mathematical functions
- **Pandas**: Data manipulation and analysis with DataFrames
- **Matplotlib/Seaborn**: Data visualization and plotting
- **Scikit-learn**: Machine learning algorithms and tools
- **SciPy**: Scientific computing and statistical functions

## Best Practices
1. Use virtual environments to manage dependencies
2. Write modular code with functions and classes
3. Use Jupyter notebooks for exploration, .py files for production
4. Follow PEP 8 style guidelines
5. Document your code with docstrings

## Data Types
- **Lists**: Ordered, mutable collections `[1, 2, 3]`
- **Dictionaries**: Key-value pairs `{"key": "value"}`
- **NumPy Arrays**: Fast numerical arrays `np.array([1, 2, 3])`
- **Pandas DataFrames**: 2D tabular data with labeled axes
