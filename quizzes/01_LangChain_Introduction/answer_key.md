# Answer Key: LangChain Introduction

---

### Q1

**Answer:** A

**Explanation:** LLM stands for Large Language Model — neural networks trained on vast text data.

**Concept:** LLM fundamentals

---

### Q2

**Answer:** B

**Explanation:** LLMs generate text from patterns. They cannot access real-time data or execute code without tools.

**Concept:** LLM capabilities

---

### Q3

**Answer:** B

**Explanation:** LangChain is a framework for building LLM-powered applications, not for training models.

**Concept:** LangChain purpose

---

### Q4

**Answer:** B

**Explanation:** LLMs are probabilistic — same input can produce different outputs, especially with temperature > 0.

**Concept:** LLM behavior

---

### Q5

**Answer:** B

**Explanation:** LangChain provides a unified interface that works with multiple LLM providers (OpenAI, Ollama, etc.).

**Concept:** LangChain value

---

### Q6

**Answer:** B

**Explanation:** LangChain has langchain-core (base abstractions), partner packages (OpenAI, Ollama), and your application layer.

**Concept:** LangChain architecture

---

### Q7

**Answer:** B

**Explanation:** Cloud APIs require internet and send data externally. Ollama runs models locally on your machine.

**Concept:** API vs Ollama

---

### Q8

**Answer:** B

**Explanation:** langchain-openai is the partner package that provides ChatOpenAI and OpenAIEmbeddings.

**Concept:** LangChain packages

---

### Q9

**Answer:** B

**Explanation:** Temperature controls randomness: 0 = deterministic, 1+ = more creative/random.

**Concept:** Model parameters

---

### Q10

**Answer:** B

**Explanation:** Hardcoded keys in code can be exposed when sharing code or pushing to Git. Always use environment variables.

**Concept:** Security basics

---

### Q11

**Answer:** B

**Explanation:** load_dotenv() reads environment variables from a .env file, including API keys.

**Concept:** Configuration

---

### Q12

**Answer:** C

**Explanation:** LangChain is a framework, not an LLM. It works with multiple providers and helps build applications.

**Concept:** LangChain purpose

---

### Q13

**Answer:** B

**Explanation:** langchain-core provides base abstractions like Runnables, prompts, and the LCEL pipe operator.

**Concept:** Architecture

---

### Q14

**Explanation:** RAG allows the LLM to search course notes and use retrieved information when answering.

**Concept:** Data Science applications

### Q15
