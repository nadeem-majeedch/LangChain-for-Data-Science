# Quizzes & Knowledge Assessment

## Overview

This folder contains pre-quizzes, post-quizzes, and assessments for each notebook.

## Learning Cycle

```
🧠 Pre-Test → 📖 Reading → 🎓 Lecture → 💻 Notebook → 🧪 Experiment → 📝 Exercise → 🎯 Assessment → 🧠 Post-Test → 🚀 Project
```

## Quiz Types

| Type | Purpose | Duration | Questions |
|------|---------|----------|-----------|
| **Pre-Quiz** | Assess prior knowledge | 5-10 min | 5-10 |
| **Post-Quiz** | Test learning outcomes | 10-15 min | 10-15 |
| **Final Quiz** | Comprehensive assessment | 60 min | 40-50 |
| **Pre-Course** | Baseline assessment | 20 min | 30 |
| **Post-Course** | Learning measurement | 30 min | 40 |

## Grading Guide

| Score | Interpretation |
|-------|---------------|
| 90-100% | Excellent — ready for advanced topics |
| 80-89% | Very Good — solid understanding |
| 70-79% | Good — minor gaps to address |
| 60-69% | Satisfactory — review recommended |
| Below 60% | Needs Review — revisit material |

**Note:** Instructors may adjust thresholds based on course difficulty.
