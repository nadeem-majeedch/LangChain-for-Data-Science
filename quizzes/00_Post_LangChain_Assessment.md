## Measuring Learning Improvement

**For Instructors:**

Compare Pre-Course and Post-Course scores:

| Score Change | Interpretation |
|-------------|---------------|
| +30% or more | Excellent learning gain |
| +20-29% | Good learning gain |
| +10-19% | Moderate learning gain |
| +0-9% | Minimal learning gain |
| Negative | Review teaching approach |

Calculate: `Learning Gain = Post Score - Pre Score`
