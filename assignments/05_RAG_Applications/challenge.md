## Course RAG Assistant

Build a complete RAG assistant for a Data Science course with source citations and quality scoring.

### Requirements

1. 15+ course documents
2. Source citations in answers
3. Confidence scoring
4. Out-of-domain detection
5. Evaluation framework

### Deliverables

- RAG assistant
- Course document collection
- Evaluation results
- Test script with 10 queries

### Evaluation Criteria

| Criterion | Weight | Description |
|-----------|--------|-------------|
| Retrieval quality | 30% | Relevant document retrieval |
| Answer quality | 25% | Grounded, accurate answers |
| Source citation | 20% | Proper attribution |
| Evaluation | 15% | Comprehensive testing |
| Error handling | 10% | Graceful failure modes |
