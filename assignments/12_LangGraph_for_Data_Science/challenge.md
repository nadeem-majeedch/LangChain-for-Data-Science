## LangGraph Research Assistant

### Requirements

1. 3+ routing paths
2. Validation node
3. Retry logic
4. State management
5. Human-in-the-loop concept

### Deliverables

- LangGraph application
- Architecture diagram
- Test results
- Performance analysis

### Evaluation Criteria

| Criterion | Weight | Description |

| State management | 20% | Proper state handling |
