## Autonomous Data Science Analyst

### Requirements

1. Full automation
2. Multiple analysis tools
3. Comprehensive output
4. Error recovery
5. Security measures

### Deliverables

- Autonomous analyst
- Analysis report for sample dataset
- Tool documentation
- Security review

### Evaluation Criteria

| Criterion | Weight | Description |

| Automation | 30% | Fully autonomous |
| Analysis quality | 25% | Insightful results |
| Tool design | 20% | Well-designed tools |
| Security | 15% | Comprehensive protections |
