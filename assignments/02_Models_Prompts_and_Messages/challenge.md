## Data Science Quiz Generator

Build a quiz generator that creates Data Science questions at different difficulty levels using structured output.

### Requirements

1. Pydantic model for quiz questions
2. Support for beginner/intermediate/advanced
3. Multiple question types (MCQ, short answer, code)
4. Quiz scoring and feedback

### Deliverables

- Quiz generator module
- Sample quizzes at each level
- Scoring system

### Evaluation Criteria

| Criterion | Weight | Description |
|-----------|--------|-------------|
| Quiz quality | 35% | Questions are accurate and educational |
| Structured output | 25% | Proper Pydantic usage |
| Difficulty levels | 25% | Appropriate complexity per level |
| User experience | 15% | Clear presentation and feedback |
