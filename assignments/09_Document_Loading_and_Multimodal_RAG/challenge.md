## Multi-Format Knowledge Assistant

Build a knowledge assistant that handles multiple document formats: Markdown, CSV, and JSON.

### Requirements

1. 3+ document formats
2. Unified search across formats
3. Format-appropriate processing
4. Metadata preservation
5. Security for untrusted documents

### Deliverables

- Multi-format assistant
- Sample documents in each format
- Search results comparison
- Security analysis

### Evaluation Criteria

| Criterion | Weight | Description |
|-----------|--------|-------------|
| Format handling | 30% | Correct processing per format |
| Search quality | 25% | Relevant cross-format results |
| Security | 20% | Document sanitization |
| Documentation | 15% | Format-specific notes |
| Testing | 10% | Edge case handling |
