## Natural Language Database Analyst

Build a natural language database analyst that translates questions to SQL and provides natural language explanations.

### Requirements

1. Multi-table database
2. NL-to-SQL translation
3. Result explanation
4. Query validation
5. Error handling

### Deliverables

- Database analyst module
- Sample database
- Test results with 10 questions
- Security analysis

### Evaluation Criteria

| Criterion | Weight | Description |
|-----------|--------|-------------|
| SQL accuracy | 30% | Correct query generation |
| Explanation quality | 25% | Clear natural language |
| Security | 25% | Query validation |
| Testing | 20% | Comprehensive test cases |
