## Safe Data Science Tool Agent

Build a Data Science agent with comprehensive safety measures including input validation, rate limiting, and audit logging.

### Requirements

1. 5+ Data Science tools
2. Input validation for all tools
3. Rate limiting
4. Audit logging
5. Error recovery
6. Security documentation

### Deliverables

- Safe agent implementation
- Security documentation
- Test results with attacks
- Audit log examples

### Evaluation Criteria

| Criterion | Weight | Description |
|-----------|--------|-------------|
| Tool functionality | 25% | All tools work correctly |
| Security | 30% | Comprehensive protections |
| Logging | 20% | Complete audit trail |
| Testing | 15% | Security testing results |
| Documentation | 10% | Security analysis |
