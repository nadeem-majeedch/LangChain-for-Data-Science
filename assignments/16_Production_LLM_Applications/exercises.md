## Level 1 — Basic

### Exercise 1: Configuration Manager

**Objective:** Implement proper configuration

**Task:** Create a configuration class that loads settings from environment variables.

**Requirements:**
- Use dataclass
- Include defaults
- Support .env file

**Expected Learning Outcome:** Student understands configuration management

## Level 2 — Intermediate

### Exercise 1: Error Recovery

**Objective:** Implement retry logic

**Task:** Add exponential backoff retry logic to an LLM application.

**Requirements:**
- Implement retry function
- Handle rate limits
- Add logging

**Expected Learning Outcome:** Student can handle production errors
