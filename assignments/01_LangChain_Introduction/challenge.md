## Multi-Provider LLM Interface

Build a Python module that provides a unified interface to multiple LLM providers (OpenAI, Ollama) with automatic fallback.

### Requirements

1. Support at least 2 providers
2. Automatic fallback on failure
3. Configuration via environment variables
4. Proper error handling and logging

### Deliverables

- Python module with unified interface
- Configuration documentation
- Test script with 5 queries

### Evaluation Criteria

| Criterion | Weight | Description |
|-----------|--------|-------------|
| Functionality | 40% | Works with all providers |
| Error handling | 25% | Graceful fallback and logging |
| Code quality | 20% | Clean, documented, testable |
| Documentation | 15% | Clear usage instructions |
